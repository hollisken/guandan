# 掼蛋训练所 · 教学型 AI 对局与训练程序

一个**零依赖、双击即玩**的掼蛋（跑得快+八十分融合的江苏牌类）训练软件。
它不只让你打牌，而是围绕一个目标设计：**用最短时间把你训练成牌桌意识和记牌能力最强的人**。

> 纯前端实现（HTML/CSS/JS，无框架、无构建、无网络请求），牌型与流程对照
> 《掼蛋竞赛规则》（国家体育总局棋牌运动管理中心审定版，另参见江苏省规则 2017/2023），
> AI 设计思路参照 DouZero 等公开项目。

的 ✘ 点评 → 每天做10题记牌训练**。教练的每一次 ✘ 都附带"更优参考"和原因，这是提升最快的闭环。

## 二、设计思路（为什么这样做）

### 2.1 参照了哪些公开项目，取舍是什么

| 参照 | 借鉴 | 取舍 |
|------|------|------|
| **DouZero**（快手，ICML 2021，斗地主AI标杆） | 动作价值评估思想：为每个合法出牌评估"这手下去会怎样"。DouZero 用自我博弈深度RL训练网络输出价值 | 本项目目标是**教学**，黑盒网络给不出"为什么"。改用**可解释特征评分体系**（见2.3），每个分数项本身就是一句讲解。牌力略逊于深度RL，但每一手都能说清理由——这正是训练器需要的 |
| **gdzero / NUAA-guandan / DanKS 等开源掼蛋RL** | 状态空间划分（手牌编码+盟友信号）、训练-推理分离的工程结构 | 采用其"规则引擎与决策分离"的分层，但不引入训练流水线 |
| **欢乐掼蛋/天天掼蛋等商业产品** | 记牌器、报牌提醒、复盘的产品形态 | 增加它们没有的：教练逐手讲解、记牌测验、残局精讲、七讲课程 |

### 2.2 分层架构

```
js/engine.js   规则引擎：牌型识别/比较、走牌生成(含逢人配枚举)、贡牌/抗贡/升级/过A/接风状态机、未现牌统计
js/ai.js       AI+教练：拆牌(decompose)→特征提取(analyzeMove)→评分决策(aiMove)→评价用户(judgeUserMove)→记忆要点(coachPanel)
js/trainer.js  训练：记牌测验生成、出牌习题生成、6道精讲残局
js/lessons.js  课程内容（《掼蛋七讲》）
js/ui.js       界面：牌桌交互、记牌器/局势/教练侧栏、结算与复盘、四个训练页
```

引擎与AI全部可脱离浏览器在 Node 里跑（`node test/smoke.js`），界面只是薄壳。

### 2.3 AI 如何决定"出什么"，以及如何"讲为什么"

参照 DouZero"为每个动作估值"的框架，用专家特征加权替代神经网络。每个候选出牌提取特征：

| 特征 | 讲解（教练面板原话示例） |
|------|------|
| goOut / oneLeft | "这手出完直接走完，无条件出！" / "出完只剩最后一手，逼近头游" |
| 炸弹时机 | "对手已报牌，用炸弹夺权防止其走牌" ↔ "轻易动用炸弹会损失后手威慑力" |
| 顶牌/让牌 | "同伴牌太小，用♠Q顶住，防止下家低价接走" ↔ "对家连对已够大，不压同伴是基本礼节" |
| 存活率(记牌) | "场上未现还有能压过它的牌，存活率不高" ↔ "未现的牌压不住它，大概率独走一圈" |
| 喂牌/禁喂 | "对家报牌(剩2张)，领出小单张给他喂牌" ↔ "对手只剩1张，出小单张等于送他走！" |
| 手数成本 | "这手拆散了原组合，手数+1" / "不在整体拆牌计划里，以后要多花一手收回来" |
| 大牌浪费 | "用大牌有点浪费，大牌要留到关键时刻控场" |
| 百搭保护 | "逢人配是百搭，单张打出太浪费——留着配顺子、配炸弹价值大得多" |

评分 = Σ(特征权重)，**AI 选最高分，教练把每个特征的解说句展示给你**。打分与讲解同源，
所以"建议"和"点评"永远一致，不会出现"AI这么做却说不出为什么"。

**过牌也是决策**：跟牌时 AI 引入"过牌基准"（同伴在管→让牌划算；对手在管→白送一圈有代价），
最好的压牌还不如过时就过——所以你不会看到 AI 拿炸弹去硬压同伴的牌、或只剩炸弹可压时被迫乱炸。
同时两条铁律进了评分：**绝不炸同伴**（-6000），**领出炸弹重罚**（-3500，除非炸完就接近走完）——
炸弹的正确用法只有三种：拦截对手报牌、夺权连击、保同伴头游。

**出牌顺序（领出技术）**——依据公开实战技术总结实现进评分：

- **小牌先走**：散单/小对是负债，值越小越先领（实测 200 个开局首领中 62% 是最小单张 3-5，开局领大单≤1%）
- **"倒数第二大牌先出"**：A/级牌/王是控场牌，前中期领出等于被对手用小牌换掉；最大的留到收官拦截
  （任何人进入 ≤6 张的收官区后解除保留，转为控场抢权）
- **难走的手先走 + 长牌示强**：顺子/三带二等长组优先领——既是清债，也是告诉同伴"这手能主攻"
- **首引信号体系**：首引小单/小对示弱（辅助打法），首引大单/长组示强（主攻打法）
- **跟同伴牌路（相互配合）**：同伴刚用单张/对子收圈时，继续领同型小牌给他续路
- **领出不看"被压风险"**：领出被对手用大牌压掉并不亏（他烧大牌、我方得信息），所以领出决策只看
  牌路配合、喂牌/禁喂攻防与手数计划——这是与跟牌完全不同的评估逻辑
- **顶牌"先大小后中间"**：对手领小单/小对且同伴没接时，要么用能压的最大单张顶到位（逼对手动级牌/王），
  要么放过省牌——绝不顶个中间牌等着被压（实测对手领小单时 AI 顶牌率 94%）；我是最后防守位时加码必顶；
  拆对顶单只算半价手数（"二个可以拆开来顶单"）；王顶小单额外罚分（王是终局裁判）
- **逢人配保护**：百搭绝不当首攻单张/对子甩出去（配顺子＞配炸弹＞留威慑＞单飞）——
  实测 150 个随机开局首领中含百搭的为 0；引擎生成单张候选时也优先用真级牌、保留百搭
- **报牌紧急态允许拆牌抢权**：对手/同伴报牌时，拆牌的手数惩罚降到三折、且不受"拆牌计划"约束——
  "助攻要坚决，即使拆自己的牌"。喂牌/禁喂还精确区分**报单与报双**：单张只能喂报单的对家、
  对子只能喂报双的；对手报双时出小对子才算送分（他一张接不住单张）
- **回手牌技术**：手上有大牌/炸弹能接回牌权时，先走小牌不吃亏——"先出难走的，回手再出想出的"

**动态配牌（随对手牌路变化的组牌）——掼蛋的精粹**：拆牌不再是"开局算好一成不变"。
`decomposeCtx` 每圈从出牌史推断配牌语境：对手跑单张路 → 拆牌惜对（对子是阻击弹药）；
对手对子示弱 → 对子/三连对是得分路更不能拆。同花顺"算总账"优先提取；"长套组小套、
单张最大化"（留下的散张尽量点大、级牌自动留外）。教练面板每圈刷新"📋 当前组牌方案(手数N)"
与变化原因——你能亲眼看到组牌是怎么随局面"变"的。实测同一手牌 5566778899：无语境拆
"同花顺+顺子"2手；对手跑单张语境改拆"三连对+三张+单张"3手（留对作阻击）。

**PIMC 残局算牌（借鉴开源跑得快AI的完美信息蒙特卡洛）**：高手难度进入残局（最短手牌≤10
或有人报牌≤4），若启发式前几名"势均力敌"（分差<400），随机采样对手持牌、各模拟到终局、
按平均升级收益微调选牌，教练显示"🎲 模拟N局"。胶着处才算牌，教学战术不被覆盖。
实测每局约5次介入、单次<100ms。

**开源/学术掼蛋AI可借鉴点（调研结论）**：
- **GuanZero**（arXiv 2402.13582）：蒙特卡洛自我博弈+深度网络（DouZero 范式）——本项目的
  "特征评分"可视为其可解释替代，未来可接 ONNX 预训练网络作为评估器
- **DanZero+**（arXiv 2312.02561）：RL 训练掼蛋智能体，状态编码方案值得参考
- **paodekuai_ai**（开源，Java）：PIMC+搜索——本项目的残局算牌即借鉴此思路的 JS 实现
- **PerfectDou**（网易，NeurIPS 2022）：完美信息蒸馏——教学上对应"上帝视角复盘"的思路
- 诚实的结论：目前没有任何公开掼蛋AI被证明稳定超越人类顶尖牌手；启发式+PIMC 的可解释
  组合对训练器是最优取舍——每一手都讲得出"为什么"，这正是黑盒网络给不了的。

**贡牌/还贡是公开信息**（规则：还牌反扣桌上，双方还完同时亮牌）：每局开始教练面板会展示
"谁贡了什么给谁、谁还了什么给谁"，抗贡时展示"谁亮了两张大王"——并提醒你把这些牌记入记牌。

**拆牌（decompose）**是"手数意识"的算法化：贪心求最少手数分解——
四天王→天然炸弹→顺子(带破坏惩罚，优先拆散单不拆对子)→连对→三带二→对/单→最后由
百搭专门补顺/补三张/升对为三。它既用于AI规划（"出这手后剩几手"），也用于教练点评"这手在不在你的整体计划里"。

**记牌（unseenInfo）**：108 − 你的手牌 − 已出的牌 = 三家手里的牌。导出三样判断：
未现各点数张数（≥4 → 炸弹风险高亮）、王的余量、各家剩牌数（报牌/报单预警）。
AI 的"存活率"特征和右侧记牌器、记牌测验全部由这一个函数驱动——**你练的记牌就是AI在用的记牌**。

### 2.4 规则实现清单（对照《掼蛋竞赛规则》/ 江苏省规则 2017/2023）

- 牌点序：大王＞小王＞级牌＞A＞K＞…＞2；级牌随局更新，红桃级牌=逢人配（可配除王外任意牌，可配成最大10张炸）
- 顺子恰5张：A2345（A作1，最小）~ 10JQKA（最大）；JQKA2 不合法；2可进顺
- **三连对(木板)必须且只能是三对相连（6张）——不可以二连对、也不可以四连对或更多**；
  **三同连张(钢板)必须且只能是两组相连三张（6张，二连三）——不可以三连三**
- 三带二(夯)：三同张带一对（不可带单张或两不同张）
- 压制：同型比点；同花顺压≤5张炸弹；≥6张炸弹压同花顺；四大天王最大
- 双下立即终局；升级：同伴二游+3 / 三游+2 / 末游+1；**打A须同伴非末游才过A**
- 贡牌：输方贡最大单张（红桃级牌除外）；**还牌：还给对方可任意（习惯还小牌），还给己方搭档才须≤10**；
  双贡时贡大牌给头游、由贡大牌者领出；**抗贡：抓到两张大王不用进贡（双贡时任一家有两大王，双下方都不用进贡）**；进贡牌公开（信息！）
- 接风(借风)：出完最后一手无人再接 → 同伴领出；一圈内"不要"满员即收圈
- **压牌自由**：能压时也可以选择"不要"（AI同样会评估后过牌）
- 报牌：剩10张须报（界面对你自动提示，AI 剩牌数常驻显示）

### 2.5 教学体系（怎么"训练"你）

1. **记忆要点常驻化**：右侧"局势"面板每圈刷新——谁报单了、谁炸过了、王的余量、炸弹风险点数、
   同伴炸弹用没用（判断他强不强）。你不用翻记牌器，关键信息推到你眼前。
2. **即时纠错**：你每出一手，教练用与AI同一套特征体系评价。好评强化正确直觉，✘当场给出"更优参考"。
3. **每局复盘**：结算面板列出你全部出手的逐条点评，✘集中看，一眼知道这局输在哪儿。
4. **主动回忆训练**：记牌训练页用"考你→核对"代替"看答案"——主动回忆是记牌成瘾式提高的唯一路径。
5. **情景教学**：6道残局每题锁定一个战术概念（顶/喂/炸/收/防双下/同花顺），讲解写清"为什么"和反例。
6. **体系化课程**：七讲从规则到意识，每讲末尾"记忆要点"可直接当口诀背。

## 五、已知简化与扩展方向

- AI 为可解释专家评分（不是深度RL），高手难度≈业余强手；想更强可在 `analyzeMove` 上加权重自学习，
  或接 RLCard/DouZero 的掼蛋移植网络作为评估器（接口已按 `genMoves → combo → score` 设计好）
- 双贡牌点大小比较按"将贡出的最大牌"自动判定；部分抗贡（一家有两王）按官方逐家判定
- 还贡AI策略是启发式（最小且不拆对）；进贡按规则自动（最大牌），符合竞赛执行
- 界面针对桌面浏览器优化（≥1100px 宽体验最佳）
- `window.__gd` 是控制台调试/托管钩子：`__gd.run()` 可同步托管整场比赛（也用于自动化测试）
